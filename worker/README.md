# שירות הביניים של דשבורד הכתבות

הקובץ `cms-relay.js` הוא שירות קטן שרץ ב-Cloudflare. הוא קיים מסיבה אחת:
האתר סטטי והתוכן שלו יושב במאגר בגיטהאב, והדפדפן לא יכול להחזיק מפתח
כתיבה למאגר, כי כל אחד יראה אותו בקוד הדף. השירות מחזיק את המפתח במקומו.

זו אותה תבנית בדיוק שכבר רצה באתר עבור כפתור הפוש (`push-relay`).

## הקמה חד פעמית

**1. אסימון גיטהאב**
GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
- Repository access: **רק** `calendboard/tzadik-magor-site`
- Permissions → Repository permissions → **Contents: Read and write**
- בלי שום הרשאה נוספת. תוקף שנה.

**2. סיסמת הצוות**
לייצר במנהל הסיסמאות, לפחות 20 תווים אקראיים. זו הסיסמה שהצוות מקליד.

**3. מחרוזת חתימה**
עוד מחרוזת אקראית, נפרדת מהסיסמה. משמשת לחתימת כרטיסי הכניסה.

**4. Cloudflare**
Workers & Pages → Create → Worker → בשם **`cms-relay`** (השם חייב להיות זה,
הדשבורד פונה ל-`cms-relay.hatzadikmagor.workers.dev`).
להדביק את תוכן `cms-relay.js` ולפרוס.

Settings → Variables and Secrets:

| שם | סוג | ערך |
|---|---|---|
| `CMS_PASSWORD` | Secret | סיסמת הצוות משלב 2 |
| `CMS_SIGNING` | Secret | המחרוזת משלב 3 |
| `GITHUB_TOKEN` | Secret | האסימון משלב 1 |
| `GITHUB_REPO` | Variable | `calendboard/tzadik-magor-site` |

Settings → Bindings → KV namespace:
ליצור namespace בשם `cms-rate-limit` ולקשר אותו בשם המשתנה **`RATE`**.
בלעדיו הכניסה תיכשל, וזה מכוון: בלי KV אין הגבלת ניסיונות סיסמה.

## מה קורה אחרי שמירה

הדשבורד → השירות כותב ל-`data/news.json` → GitHub Action `build-site.yml`
בונה מחדש את `a/<id>.html` ואת `sitemap.xml` → GitHub Pages מפרסם.
בסך הכל 2 עד 5 דקות מרגע השמירה ועד שזה באתר.

## מה מוגן ואיך

- **הסיסמה נבדקת רק בשרת**, בהשוואה בזמן קבוע. היא לא נמצאת בקוד האתר.
- **הגבלת ניסיונות**: 8 כשלונות מאותה כתובת IP חוסמים אותה לרבע שעה.
- **כרטיס כניסה זמני**: אחרי כניסה מוצלחת נשלח כרטיס חתום שתקף 8 שעות,
  כך שהסיסמה עצמה לא נשלחת בכל פעולה.
- **סוגי קבצים**: רק תמונות, סרטונים והקלטות. קובץ HTML או קוד נדחה,
  אחרת אפשר היה להעלות דף זדוני לתוך הדומיין שלנו.
- **שמות קבצים**: נתיבים מנוטרלים, הקובץ תמיד נוחת ב-`assets/news/`.
- **גודל**: עד 25 מגה לקובץ. סרטונים כבדים עולים ליוטיוב.
- **הרשאת האסימון**: כתיבה למאגר הזה בלבד, בלי גישה לשום מאגר אחר.

## בדיקות

```
node worker/test_worker.mjs   # לוגיקת השירות מול מאגר מדומה
node worker/test_client.mjs   # השרשרת המלאה: דשבורד -> שירות -> מאגר
```
